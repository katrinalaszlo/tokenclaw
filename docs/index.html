WHAT IT DOES

Credit card fraud alerts for AI spend

Your bank texts you when a suspicious charge hits. This does the same thing for your AI tools.

⚲

Auto-discovers your tools

Finds Claude Code, OpenClaw, Cursor, Windsurf, Aider, and more. Reads local session files. No API keys needed for scanning.

⚐

Escalating alerts

Not a one-time notification. If you don't acknowledge, it gets louder. Every 4 hours, then every 2, then hourly. Until you say "this is OK."

✓

Acknowledgment loop

Reply "ok" in Slack or run agentcap ack in your terminal. Silences for 24h. If spend keeps rising, it alerts again.

↑

Rate-based detection

"Your spend jumped 3x from yesterday" is more useful than "you've crossed $100." Detects velocity, not just thresholds.

🔒

Privacy-first

Everything runs locally. No cloud. No telemetry. No accounts. Session data and prompts never leave your machine.

$

Subscription vs API

Shows both numbers: what you consumed (token estimate) and what you paid (subscription). So you know if your plan is worth it.

HOW IT WORKS

Install. Scan. Forget.

1

Install

npx agentcap — scans your machine for AI tools, shows what it found, asks where to send alerts. 60 seconds.

2

It watches

Runs in the background via cron. Checks spend against your thresholds. Compares today to your baseline. You don't think about it.

3

It yells when something's wrong

Slack message: "OpenClaw spent $194 in 6 hours. Your daily avg is $90. Reply ok to silence." If you don't reply, it keeps yelling. Louder each time.

INSTALL

One command. 60 seconds.

No signup. No accounts. No code changes. Runs locally on your machine.

Quick scan (see what you're spending)
$ npx agentcap
Scans your machine, shows spend across all AI tools, exits. Nothing installed permanently.
Set up monitoring (get alerts when something's wrong)
$ npx agentcap init
Interactive setup: set thresholds, connect Slack, start background monitoring. Config saved to ~/.acc/config.yaml
Or install globally
$ npm install -g agentcap
Then use agentcap directly. Requires Node 18+.
