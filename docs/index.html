They're not malicious. They're just agents doing agent things with no spending limit. Anthropic has monthly workspace caps. OpenAI turned their hard limits into emails. Nobody has per-key daily budgets. That's what tokenclaw is.

what tokenclaw actually does

Local proxy between your agents and the API. Every request goes through it. Budget's gone? Request blocked. Your agent gets a 429 and a very clear "you're done for today."

🛑

hard caps per key

$10/day on the research agent. $100/day on deploy. Budget gone? 429. Blocked. Not a warning. Not an email. Blocked.

⚲

anthropic + openai, one proxy

Figures out which provider from the request path. Also works with Groq, Together, Fireworks. Anything OpenAI-compatible.

✓

see who's spending what

tokenclaw keys and there it is. Per key, per day. No more guessing which agent ate your budget.

🔔

slack alerts that won't shut up

Research agent gets $10. Deploy agent gets $100. One goes rogue, the other keeps working. The crab is very strict about this.

3

start the proxy

tokenclaw proxy on localhost:4040. Point your agents at it. The crab watches every request. Over budget? Nope. 429. Try again tomorrow.

install

$ npm install -g tokenclaw-dev
$ tokenclaw set --key sk-ant-proj-research --budget 10/day
$ tokenclaw proxy
$ ANTHROPIC_BASE_URL=http://localhost:4040 claude
