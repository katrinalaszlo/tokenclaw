You know the problem.

Agent ran overnight. Bill was $280. OpenAI's "spending limit" was just an email. Anthropic's caps are monthly and workspace-level. Nobody does per-key. Nobody does daily. You're always finding out after.

⚐

No kill switch

Dashboards show you numbers. Alerts email you after. Nothing actually stops the request from going through at 3am.

↑

Monthly limits miss everything

Agent loops. Runaway retries. A "quick test" that scans your monorepo twice. All under your monthly cap. All expensive.

⚲

Which agent is spending what?

Three agents, one API key. No way to tell who's burning through your budget. Per-key budgets fix that.

What tokenclaw does

Local proxy between your agents and the API. Counts tokens. Checks budgets. Blocks the request if you're over. That's it.

🛑

Hard caps per key

Daily, weekly, or monthly. Budget gone? 429. Agent stops. Not a warning. Not an email.

⚲

Anthropic + OpenAI

Auto-detects from the request path. Also works with Groq, Together, Fireworks, anything OpenAI-compatible. One proxy.

✓

See who's spending what

tokenclaw keys shows spend vs budget per key. Unregistered keys get tracked too, just not limited.

🔔

Slack alerts

80% warning. 100% blocked. Gets louder if you ignore it.

🔒

Runs on localhost

No cloud. No telemetry. No account. Your requests never touch a third party.

Scan your tools

Three steps.

1

See what you're spending

Run npx tokenclaw-dev. It finds every AI tool on your machine and shows you the numbers.

terminal
$ npx tokenclaw-dev
Scanning AI tools...
What you paid: $200/mo (Max subscription)
What you consumed: ~$12,570 at API rates
found Claude Code 416 sessions ~$12,570
tanso-dashboard ~$4,200
tanso-core ~$3,800
personal-site ~$890
found OpenClaw 23 sessions ~$340
found Cursor 89 sessions Pro $20/mo
2

Set budgets

tokenclaw set --key sk-ant-proj-research --budget 10/day
One key per agent. One budget per key. Runaway on one can't touch the other.

3

Start the proxy

tokenclaw proxy on localhost:4040. Point your agents at it. Over budget? Blocked.

🔔 Slack
[tokenclaw] Key budget exceeded: sk-ant-proj-research
$10.42 spent (limit: $10.00/day)
Requests blocked until midnight UTC
The agent tried to keep going. We said no.

$ npm install -g tokenclaw-dev
