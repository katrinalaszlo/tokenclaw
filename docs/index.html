WHAT IT DOES

Spending authority lives on the key

One key per agent. One budget per key. A runaway on one key can't touch the other. 13+ competitors do account-level caps. This does per-key.

⚐

Hard budget caps

Not a soft limit. Not a warning. The proxy returns 429 and blocks the request. The agent can't spend past the budget. Period.

⚲

Multi-provider

One proxy handles Anthropic and OpenAI. Auto-detects provider from request path. Covers Claude Code, OpenClaw, GPT agents, and any OpenAI-compatible API.

✓

Per-key tracking

See exactly how much each API key has spent. Daily, weekly, monthly budgets. Longest-prefix matching for key rotation.

↑

Escalating alerts

Slack alerts at 80% and 100% of budget. If you don't acknowledge, it keeps yelling. Louder each time. Plus escalating account-level alerts.

🔒

Local-first

Everything runs on your machine. No cloud. No telemetry. No accounts. Requests proxy through localhost, never through a third party.

$

Scan without proxy

Also scans 9 AI tools on your machine (Claude Code, Cursor, Windsurf, Aider, etc.) and shows what you're spending. No API keys needed.

HOW IT WORKS

Set budgets. Start proxy. Done.

1

Set per-key budgets

tokenclaw set --key sk-ant-proj-research --budget 10/day — each API key gets its own spending limit. Daily, weekly, or monthly.

2

Start the proxy

tokenclaw proxy starts on localhost:4040. Point your agents at it with ANTHROPIC_BASE_URL=http://localhost:4040 or OPENAI_BASE_URL=http://localhost:4040.

3

Budget exceeded? Blocked.

The proxy returns 429. The agent sees a clear error with the exact CLI command to increase the budget. Slack alert fires. No spend slips through.

INSTALL

Three commands. Two minutes.

No signup. No cloud. Runs on your machine. Requires Node 18+.

Install
$ npm install -g tokenclaw
Set per-key budgets
$ tokenclaw set --key sk-ant-proj-research --budget 10/day
$ tokenclaw set --key sk-proj-deploy --budget 100/day
Start the proxy
$ tokenclaw proxy
# Point your agents at it:
$ ANTHROPIC_BASE_URL=http://localhost:4040 claude
$ OPENAI_BASE_URL=http://localhost:4040 your-agent
Proxy supports
Anthropic OpenAI + any OpenAI-compatible API
