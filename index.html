FEATURES

Complete agent spend control

Everything you need to track, limit, and attribute AI agent costs across every provider.

🔍

Multi-Provider Metering

Unified cost view across Anthropic, OpenAI, Google, and custom tool calls. One dashboard, every dollar.

🛡

Budget Envelopes

Set spend limits per agent, per day, week, or month. Agents check their budget before every API call.

⚡

Real-Time Alerts

Threshold warnings at 80%, hard caps at 100%. Get notified before spend spirals, not after.

🔴

Kill Switch

One-click pause on any agent. Auto-pause when budgets hit hard caps. No more runaway spend at 3am.

📊

Cost Attribution

Know which agent spent what, on which task, with what outcome. Per-request cost tracking with full context.

🔑

Agent Identity

Register every agent and workflow with a unique ID. Track spend from the first API call to the last.

HOW IT WORKS

Three lines of code

1

Wrap your API client

Import the ACC SDK and wrap your existing Anthropic or OpenAI client. One line, zero behavior change.

const client = acc.wrap(new Anthropic(), { agent: 'code-reviewer' })

2

Set budgets in the dashboard

Define spend limits per agent — daily, weekly, monthly. Set alert thresholds and kill switch rules.

3

Watch the spend

Every API call is tracked, attributed, and checked against budgets in real-time. See exactly where every dollar goes.
